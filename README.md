# EmeraldBox

![emeraldbox](emeraldbox.png)
EmeraldBox is a project that makes a one-on-one port of Garry's Mod to nillerusr's Source Engine Android project, basically meaning that you can run GMod, but on an Android device.

this project is an archive of Half-Life 2: Sandbox++ with the permission from YourLocalMoon also known as ThePixelMoon, meant to archive most of the files needed all in a github repo for people to play garry's mod on mobile, as it was a very good concept that did have potential (before it was trashed), and this repo was made to revive the idea, with developers still maintaining and updating this project to this very day.

this archive will feature many of the things from hl2sb++ and hl2sb+++ (Half-Life 2: Sandbox ++ Revamp) including new stuff as well, stuff like addons, files, apks, releases, etc.
